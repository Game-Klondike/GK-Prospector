# GK Prospector

**Українською.** Програма для Windows — помічник сайтів Ігрового Клондайку: читає збереження ваших ігор (лише читає, нічого в них не
змінює) і ставить позначки прогресу на сайті у вашому браузері. Зараз підтримується S.T.A.L.K.E.R. 2
(сайт [Zone Companion](https://stalker2.gameklondike.pp.ua)); інші ігри Клондайку додаватимуться.
Працює тільки на вашому комп'ютері й нічого не надсилає на сервери.

**Завантажити:** [Releases](../../releases/latest) → `GK-Prospector.exe`. Запустіть його й натисніть «Встановити й підключити».
Видалити: значок біля годинника → зняти «Запускати разом з Windows» → «Вийти», потім видалити папку
`%LOCALAPPDATA%\GK-Prospector`.

**English.** A Windows helper for Game Klondike sites: it reads your game saves (read only, never changes them) and ticks
your progress on the site in your browser. Supported now: S.T.A.L.K.E.R. 2 ([Zone Companion](https://stalker2.gameklondike.pp.ua));
more Klondike games will follow. It runs only on your computer and sends nothing to any server.

**Download:** [Releases](../../releases/latest) → `GK-Prospector.exe`. Run it and press «Встановити й підключити» (Install and
connect). To remove: tray icon → untick «Запускати разом з Windows» (start with Windows) → «Вийти» (exit), then delete
`%LOCALAPPDATA%\GK-Prospector`.

Problems and ideas: [GK-STALKER2-COMM](https://github.com/Game-Klondike/GK-STALKER2-COMM/issues).
